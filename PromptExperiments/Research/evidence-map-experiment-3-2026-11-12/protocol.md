# Experiment 3: explicit evidence map, frozen before live execution

Hard cap 18 GPT-6 Luna HTTP requests: 6 source-only maps and 12 single-shot judges, zero retries, no regeneration, no repair or other live model calls. Every started attempt consumes a slot including failures. A global exclusive run lock and immutable attempt directories prevent replay. All maps run first, then a separate unblinded evaluator audit is saved before judges start. No map correction or labels are supplied to judges. Invalid maps are retained and mark a gate failure; judge still receives raw map plus source to test recovery. No tuning after freeze, no reallocation of unused calls.

Six source/Idea pairs: unchanged historical intro/005/010 and three newly authored unrelated holdouts. Each map is reused unchanged for a defective and correct Research document. Historical baselines and controls are copied byte-for-byte from Experiment 2; 005 uses control-005-complete (the old partial control is excluded). The new holdouts have no prior model evaluation; they are independent of historical sources, not independently human-authored/labeled. The same assistant authors labels and evaluates outcomes, unblinded. No claim of independent validation.

Freeze protocol, generic prompts/rubric, cases, reference coverage labels, runner and hard budget using SHA256 before any call. Exact source anchors in reference labels are validated before freezing. Record full requests/responses, provider model, usage, HTTP metadata, raw and parsed maps/verdicts/errors, real SynthesisResearchFilter output. Never record credentials. Judge uses same verdict contract and is checked with strict duplicate/unmapped-property rejection and original-source substring validation equivalent to production. The actual production ResearchSemanticJudge parser is also replayed offline against every captured judge answer.

Map audit: score each frozen material reference item covered/partial/missing; for every map entry assess source support, exact anchor validity, relevance/materiality and scope. Exact substring is necessary, not sufficient. A missing historical target is a mapper failure; if mapped correctly but missed by judge, judge failure; unsupported mapping amplified by judge is both. Correcting an invalid map internally is not map success. Record ambiguity conservatively. Negative controls need not exist in every source; never invent them.

Judge rubric/gates: all three historical target defects explicitly and faithfully diagnosed, not merely rejected; three correct historical controls accepted without material false positives; all map and diagnosis anchors valid and semantically supporting; all materially required map items covered, no material invented evidence; all three new defective holdouts faithfully detected and all three correct holdouts accepted without serious regressions. All gates required. Assess materiality as changing permissible conclusions, not detail or wording preference. Unknowns may retain legitimate uncertainty about unmeasured effects or precise implementation despite attributed source meaning/broad status.

No production prompts, filter, workflow, ResearchAgent or EnableResearchJudge changes; no activation, Copilot CLI, commit or push. Even GO requires explicit later approval for production integration. Compare matched six historical judge cases and amortized map overhead against Experiment 2; separate nonmatched holdouts and whole-run cost. Tokens, not invented monetary prices. Single shot, small sample, shared map errors and unblinded judgments limit inference. Run offline solution build/tests, runner self-checks, protected-file integrity checks. Report critically in Dutch and preserve all markers even on NO-GO.
