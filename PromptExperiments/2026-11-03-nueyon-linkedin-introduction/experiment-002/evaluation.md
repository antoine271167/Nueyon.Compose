# Experiment 002 evaluation

**Decision: REGRESSION — not promoted.**

The candidate used the frozen brief, workflow instruction, model, configuration, and pipeline. Only the Narrative user prompt differed from the production baseline. The updated prompt clarified that a company introduction should retain company-level scope and treat technical detail as support.

| Criterion | Result | Evidence |
|---|---|---|
| Targeted story focus | Improved | Narrative explicitly identifies the company introduction and Compose as the first concrete direction. |
| Selected Idea alignment | Improved | Narrative foregrounds Nuëyon’s intended audience, identity, and Compose rather than presenting an unrelated agent-to-orchestrator history. |
| Factual integrity | Regressed | Candidate invents article readership groups (“early adopters” and “potential collaborators”) and process steps (“capturing and indexing,” “structuring an outline,” “preparing the output for publication”). These are absent from the brief. It also says the initial implementation “validates” a workflow, which overstates source material describing a roadmap priority to build and validate it. |
| Agent responsibility | Regressed | Narrative and Compose include editorial meta-text (“The brief’s central idea” / “This note is for…”) rather than defining and presenting the subject. |
| Completeness | Improved in Narrative, not Compose | Narrative mentions broader directional plans, but the final post does not explain the roadmap stages. |
| Relevance | Improved | The company introduction is now the clear top-level subject. |
| Clarity | Regressed | The final post introduces unestablished reader categories and a list of unsupported workflow steps. |
| Focus | Regressed | The post expands to six paragraphs, repeats the first-step idea, and adds technical process detail. |
| Readability | Regressed | “This note is for…” sounds like a briefing document, not a natural company-page post. |
| LinkedIn format | Mixed | Paragraphs and hashtags are present, but the opening is not compelling and the editorial meta-text undermines publishability. |
| Overall usefulness | Regressed | The target focus improved, but unsupported claims materially fail the mandatory factual-integrity gate. |

## Before and after excerpts

**Baseline Compose:** “Nuëyon is an early-stage, AI-first software company…”

**Candidate Compose:** “This note is for AI founders, product leaders, early adopters, and potential collaborators…”

The candidate makes the intended company-level scope explicit but invents audiences and process details, and it remains too technical for the requested introduction.

## Promotion

Not promoted. The candidate is preserved here; the production prompt was restored from the frozen baseline snapshot.
