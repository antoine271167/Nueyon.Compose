# Experiment 004 evaluation

**Decision: REGRESSION — not promoted.**

Three baseline and three candidate full-pipeline runs used the same input, OpenAI model (`gpt-5-mini`), application settings, and unchanged upstream prompts. Only `Compose.linkedin.user.prompt.txt` differed in the candidate condition.

| Criterion | Baseline (3 runs) | Candidate (3 runs) | Result |
|---|---|---|---|
| Opening specificity | All three opened with an identity statement or a reader list. | All three still opened with an identity statement. None led with a supported observation or tension. | Unchanged; target gain not observed. |
| Ending redundancy | Runs 1 and 3 restated the main company/product point; run 2 ended with a qualification. | All three returned to the same “first step / AI-first identity” point in the ending. | Unchanged; target gain not observed. |
| Factual integrity | No clear unsupported claim in the opening/ending samples used for this comparison. | Run 3 names “AI-first founders, product leaders, and early-stage SaaS builders” as the audience. The source identifies AI-first companies as the intended audience and says customer segments are not finalized; these reader/customer categories are not established. | Regressed; factual gate fails. |
| Focus/readability | Outputs varied in length and level of detail; several were technical. | Outputs remained technical and repeated the first-product framing. Run 2 added an unsupported rhetorical contrast about “hoping generative output lands where it needs to.” | Regressed in one sample. |
| LinkedIn format | Short paragraphs, but the openings were not consistently compelling. | Short paragraphs remained, but there was no consistent hook improvement and no reduced repetition. | Unchanged. |

## Evidence

**Baseline openings:** “Nuëyon is an emerging AI-first software company…”; “Founders, product leaders, early partners and technologists…”; “Nuëyon is an early-stage, AI-first software company…”

**Candidate openings:** “Nuëyon positions itself…”; “Nuëyon is an emerging AI-first software company…”; “Nuëyon is defining its AI-first identity…”

The candidate endings all repeated that Compose was the first step that made the company’s AI-first direction tangible. The prompt change did not consistently produce a more specific opening or a less repetitive ending.

## Promotion

Not promoted. The candidate prompt and all six run logs are preserved. The original Compose LinkedIn prompt was restored from the rollback copy.
