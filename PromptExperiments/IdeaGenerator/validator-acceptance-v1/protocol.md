The expected labels and reasons are in the two case manifests. The candidate was fixed before authoring the ferry pair. No prompt changes after freezing.

One candidate only. Run baseline and candidate on all 10 tuning cases. Manually score each emitted blocker for correct material mismatch and field, faithful source evidence, and constraint bounded by the source without suggested copy, alternate angle, intervention choice or added research. Record errors separately from the confusion matrix. The positive class is BLOCK. Report TP/FP/TN/FN, precision and recall, each false accept/reject and diagnosis quality. Select by fewer errors, with false accepts taking precedence, then fewer deficient diagnoses, then baseline on ties. Lock selection before any live holdout. Compare both conditions on the two ferry cases after lock. Repeat 005-b and 010-b once per condition and compare verdict and diagnostic quality.

Maximum 28 paid requests: 10 + 10 tuning, 2 + 2 holdout, 2 + 2 repeats. Transport retries disabled and one request allowed per process. No replacement calls. A live failure occupies its slot. Model alias gpt-5-mini, provider resolved model archived if available. Authorization follows from the explicit request to execute the live experiment with a low budget. No credential values recorded.

Promotion gate: candidate must improve tuning false accepts or diagnosis quality, have zero false accepts and false rejects across tuning and holdout, emit only faithful non-prescriptive diagnoses that cover the material issue, and maintain those outcomes on repeats. Passing is grounds for a larger confirmation trial, since this single synthetic holdout pair is too narrow to establish production reliability on its own. No production edits during this experiment.
