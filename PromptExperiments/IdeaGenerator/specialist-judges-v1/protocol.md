# Frozen protocol — specialist judges v1
HEAD f894d2f161e034aa514a7ce138eb2ba278b3cffe. No commits or pushes.
Maximum 176 paid GPT-5-mini calls: 112 judge-only (32 regression/tuning + 64 holdout + 16 repeats), 64 conditional full-loop calls. No transfer, replacement or SDK retry. A reserved failed call counts. At most 3 concurrent calls. Existing C# harness is copied byte-for-byte, production parser/schema/adapter reused, one fresh process per call. Combination is AND acceptance / union of blockers; any invalid/missing specialist response fails closed. Both specialists always run; no short circuit. Combination adds no paid call. Baseline and v2 each cost one call, split costs two. Report raw and per-call costs; no claim of budget-neutral superiority. Two-repeat baseline/v2 ensembles can be assessed only on repeat cases, not inferred elsewhere.
One specialist prompt pair only; no adaptive optimization. All prompts, labels, sources, scripts and source hashes frozen before calls. 8 historical regression cases include original v4 005 and 010 plus clean counterparts. 16 new holdout cases are 8 paired families, not 16 independent sources. Repeat 005-b, 010-b, v4-005-original and v4-010-original once, all four conditions. Holdout is not used for tuning or selection. No independent human review is available: labels are same-author, frozen before results; diagnoses are conservatively reviewed against entire source. This cannot establish broad population reliability.
Positive class = material blocker. Report TP FP TN FN, precision, recall, false accepts/rejects, per-remit specialist scores, split union and stability. Source-only is not penalized for pure editorial errors (nor vice versa); overall split is evaluated on every label. Blocker quality requires exact real mismatch, faithful complete diagnosis, declarative non-prescriptive constraint, no invented requirements or correction fields. Review every blocker; uncertainty fails gate.
GO requires: no transport/schema failures, zero combined false accepts or false rejects on tuning, holdout and repeats; all critical errors actually diagnosed, not merely rejected for another reason; 100% complete source-faithful non-prescriptive blockers; 100% repeat agreement; strictly fewer false accepts than BOTH comparators with no greater false rejects. Also require at least 5 paired discordances favoring split and zero against each comparator on unique families (one-sided exact sign p<=.03125); report family dependence and small sample. Without independent human review all conditions above remain mandatory. Failure gives NO-GO and leaves production intact. Stop after scheduled judge experiment; no prompt fishing.
Only after GO may Copilot CLI modify C# production/tests (verified claude-haiku-4.5 preferred). Original source and editorial task authoritative, diagnosis only, strict parsing and explicit failure at exhaustion. Retain conservative current cap of 3 total generations (2 retries, within requested maximum of 3 retries). Build/unit/integration tests then at most 64 actual adapter calls for complete-loop controlled cases, log each generator/specialist invocation before dispatch; validate repairs against original source, preserve valid fields and purpose, include exhaustion and malformed response tests. No model calls outside ledger. Production acceptance can fail even after architecture GO.
Reproduction: python run.py offline, then tuning, holdout, repeat; python score.py. Reserved slots never rerun automatically; failures are audited. Resume using existing ledger and frozen manifest. Do not re-run prepare.py after freeze.
