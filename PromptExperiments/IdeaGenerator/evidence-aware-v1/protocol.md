# Evidence-Aware Idea Generation Experiment v1

Preregistered 11 November 2026, Europe/Amsterdam. Repository HEAD e9f302ada8052635094bfa3b5297e7b76a93cdea, fetched and equal to origin/main; initial working tree clean. No commits, pushes or production promotion authorized.

Question: does explicit evidence grounding (B), or grounding plus a separate review (C), improve selected-first editorial ideas over the actual production Idea Agent (A), without losing editorial appeal?

## Design and freeze

Ten source families: the exact v4 wrapped inputs for original 005 and 010 are development/tuning regressions; eight newly authored synthetic sources are holdouts. They are unseen by the generator before their own calls, not independent real-world samples. Prompts were written before new holdout sources. No paid tuning, prompt selection or post-result prompt edits: one candidate fixed for all families. Prior v4, validator v1/v2 and specialist-judges sources/results informed failure classes, never become hidden holdout examples. Only the selected source reaches each fresh model context; labels, other cases, rubric and earlier outcomes are excluded. Prompt/schema differences are the intervention.

Before any paid model call, freeze cases, labels, rubric, prompts, protocol, run scripts and C# source/schema with SHA-256 in verification/frozen.json. Labels describe permissible claim boundaries and editorial purpose, not one mandatory title. Freeze refuses regeneration. Source comparison must use complete original text, including qualifications. Freeze timing and first reservation establish chronology. New holdouts share an author with prompts/rubric and evaluation. No independent human blinding or external human review is available; the evaluating Work assistant is an AI, not a human judge. This is traceable editorial assessment, not independent validation or a new automated judge service.

## Conditions and parameters

A runs unchanged production IdeaAgent, IdeaValidationLoopEvaluator, structural validator and production semantic judge through MAF, including up to three generator attempts with corresponding judge calls. B runs one fresh MAF evidence-aware generation with an isolated strict experimental schema. C starts from the exact saved B draft and uses one fresh MAF review/revision call; its end-to-end cost includes B. No concealed regeneration, sampling selection or schema repairs. A retains its existing JSON contract. B/C grounding is a public claim-to-quote justification, not a request for private reasoning. Matching quotes are mechanically checked; entailment requires source comparison.

All use the same OpenAI Chat Completions IChatClient adapter and gpt-5-mini alias, SDK retries zero, no temperature/seed override, identical maximum output allocation (6000 if implemented). Save actual model ID/options/finish reason. A's shipped workflow includes a judge unlike B; primary comparison is workflow-level, not an equal-call causal estimate. C reuses B so paired correction assessment is exact, but B/C results are dependent. No full downstream Research/Narrative test is part of this study.

## Primary and secondary outcomes

Score the first final idea only, all five fields together. Five 0–2 criteria in rubric.md. A cell passes iff valid output AND fidelity=2 AND intent=2 AND total>=8. Failure/invalid/blocked counts as failure; no winner-only exclusion. Report ten-family primary totals separately from four repeated families, never count replicates as independent families.

Conservative GO for a candidate: at least 8/10 primary passes, at least 7/8 holdout passes, both original005/010 pass on both replicates; at least three more primary passes than A; no new critical source/intent failure where A passes; mean (distinctive+appeal) >=A; mean appeal >=1.5; all planned cells valid. C additionally needs >=2 genuine source/intent repairs of B failures, no harmful revision or new unsupported diagnosis, and at least two more primary passes than B. These thresholds are intentionally screening rules, not a significance claim. With ten families, report descriptive paired wins/losses and uncertainty; no population reliability or superiority claim. If insufficient proof, NO-GO, even if a numerical improvement appears.

Record evidence quotation validity, whether grounding actually supports the associated claim, coverage of material claims, causal/intervention overclaims (counts and exact fields), execution/schema failures, focus, angle and appeal, calls/tokens/cached/reasoning/latency. A lacks experimental structured grounding by design, not automatically evidence-free: inspect its evidence field. For C compare exact B/C text, review issues and revised claims; distinguish repairs, harmless edits, no change, regressions and ungrounded diagnoses. Assess review issue quality separately from final quality. No live AI scoring calls; all conclusions trace to saved source/idea passages.
