# Frozen protocol, before live calls
30 source/idea cases: 22 tuning (11 good, 11 bad), 8 final holdout (4 good, 4 bad), 15 contrast pairs. Six exact v4 originals verified against traces, paired with correct counterparts; five v1 minimal pairs; four newly authored holdout pairs. v4 counterparts may differ in multiple fields; v1/holdout contrasts change one field. Sources/reasons/labels never sent to model except source and idea. Same author prepares and scores; holdout is unseen by model and not used in tuning, not externally blinded from author. No claims of independent human review.
Both candidates fixed before holdout authorship and any live call. No prompt revisions. Baseline + two candidates all evaluated on tuning. Select candidate on tuning recall, then fewer false rejects, then diagnosis quality; ties choose candidate1. Freeze selection before holdout. All three run holdout for comparison; never reselect or revise from holdout. Repeats: 005-b, 010-b, museum-b, v4-005-original, v4-010-original, v4-transit-original once each under all three conditions, after selection. One initial + one repeat measures limited agreement, not robust variance.
Budget: maximum 108 logical AND transport requests (66 tuning + 24 holdout + 18 repeats); SDK retries zero, no replacements for failed slots, max concurrency 3, fresh process/session each call. User explicitly requests paid GPT-5-mini calls; authorization within this fixed budget. Exact token usage recorded, no estimated price assumed. Model alias gpt-5-mini; resolved IDs logged. No temperature/seed override. 90 second network, 100 second judge timeout. No generator calls.
Positive class=material error requiring rejection: TP rejected bad, FN accepted bad (false accept), FP rejected good (false reject), TN accepted good. Errors/invalid schema reported separately and fail gates, never counted as successful blocks. Report each split and pooled unique cases, repeats separately. Precision=TP/(TP+FP), recall=TP/(TP+FN). Wilson 95% intervals on unique negative cases; correlated contrasts limit interpretation.
Gates: zero missed known critical cases including all six v4 originals and all repeat bad cases; >=95% recall unique cases and holdout; zero false rejects on known good and holdout; every blocker in every candidate call must identify a real mismatch, be entirely source-faithful and non-prescriptive. Any fabricated premise, inflated claim, invented decision criterion, replacement wording, intervention/research instruction fails the diagnosis gate. Declarative source-imposed limits are allowed. Score every blocker manually against frozen source/reason and inspect unexpected extra blockers. Verdict correctness alone is insufficient. All offline contract probes/build/tests pass; production integrity unchanged. Only the preselected candidate could be promoted if ALL gates pass. Small samples cannot establish population recall >=95%; report that uncertainty even for perfect samples. Otherwise no production change, assess split-judge next experiment. No commits/pushes.
