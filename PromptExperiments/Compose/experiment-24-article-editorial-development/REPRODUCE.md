# Reproduction

Use the source commit in model-configuration.json, Windows with .NET SDK 10.0.404, Node 22 and authenticated production OpenAI and GitHub Copilot CLI environments. Exact checked-out production prompt bytes are in the freeze. Git line ending conversion may need to match this Windows checkout to verify these external files. A is the exact Git blob. Candidates use one Article-only insertion each. The runner creates temporary copies of the production prompt tree and uses the existing CLI --prompts option. No contract, application code or configuration edits are required.

Run from the repository root. Set EXP24_COPILOT_LOADER to the npm-loader.js next to the installed Copilot wrapper, in node_modules/@github/copilot. Build with dotnet build src/Nueyon.Compose.slnx. The checked-in archive retains the original fixtures. Use a separate copy with fresh output and review directories to generate a new sample, retaining the frozen plan and datasets. To reconstruct a new set of fixtures in a fresh experiment directory, use run.cjs prepare, narratives and freeze. Narrative generation in that case may differ from the checked-in sample.

Use node run.cjs verify to confirm frozen input bytes. Run generate development, then review development editorial, review development factual, and review development factual 2. Resolve disagreements in adjudications.json from authoritative evidence. Run analyze.cjs select to record the prospective selection. Run the same generation and three review stages with holdout. The reviewer reads only the stored request text, through an independent invocation per output and pass. Raw reviewer logs are retained. The analyzer applies the Experiment 23 normalization for named score objects and labels accompanied by their descriptions. If a review cannot be normalized and its excerpts verified against the complete Article, that review has incomplete coverage. It never silently becomes a factual pass.

Use analyze.cjs issues holdout to locate material disputes, unresolved evidence and missing review coverage. Recalculate metrics and score/findings CSVs with node analyze.cjs. Use node gates.cjs to recalculate the gates. Do not carry prior adjudications over to new sampled outputs. Model defaults allow sampled outputs to vary. Read started.json, attempt.json and logs for failures. The runner preserves any completed attempt and stops on an unresolved attempt directory, avoiding silent replacement. A paid credential smoke probe used a historical Article fixture and is outside the frozen plan.

Run node stress-check.cjs to recalculate the anchor-source findings on this exact archive. It contains literal checks on named historical stress claims and the flagged title scopes. Source-review-rules.json records primary-source decisions on reviewer interpretations. Use verify.cjs to verify all generation attempts, independent review linkage, excerpt examples and frozen production boundaries.
