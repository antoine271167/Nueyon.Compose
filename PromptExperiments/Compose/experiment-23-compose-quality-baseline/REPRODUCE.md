# Reproduce

Use the repository root, the source commit recorded in model-configuration.json, SDK 10.0.404, Node 22.16.0, and authenticated OpenAI and GitHub Copilot environments with GPT-6 Luna. The production console uses its own machine configuration and the reviewer uses an authenticated Copilot CLI. No credential values belong in artifacts.

Set EXP23_COPILOT_LOADER to node_modules/@github/copilot/npm-loader.js next to the installed copilot.cmd. Build with dotnet build src/Nueyon.Compose.slnx. Run node <experiment-dir>/run.cjs verify. Use a separate copy of the experiment with empty outputs and reviews for new samples. Run the same script with generate, editorial and factual. Run review-extra.cjs second --final to select secondary reviews from the normalized factual labels. Each stage archives distinct attempts and refuses to overwrite incomplete attempt directories. Preserve the frozen fixtures. Review exact source and Narrative evidence before regenerating adjudications, then run node <experiment-dir>/adjudicate.cjs and node <experiment-dir>/score.cjs. The adjudication script encodes decisions on the archived drafts and must be re-evaluated on newly generated content. Verify a delivered archive with node <experiment-dir>/verify.cjs. Model defaults allow new generations to differ.

The production Compose CLI parses the schema and writes the full reader-facing content, preserved verbatim within result.json. It does not expose raw HTTP text, rejected response bodies, token usage, or per-request cost. Review stdout and stderr are archived as returned. Hashes cover fixture, policy, code and production prompt bytes. The experiment .gitattributes preserves those bytes in Git.
