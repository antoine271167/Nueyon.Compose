# Production baseline

The working branch was main at 9d6ebe8ab20c7d27a6ad4f6eac1aa34b1b435614, equal to fetched origin/main. The [freeze](freeze.json) records SHA-256 for each prompt and settings file. The [model configuration](model-configuration.json) gives runtime aliases and tooling. The authenticated Copilot probe separately returned READY for gpt-6-luna. Machine credential values were excluded. No resolved provider build version was exposed.

- ComposeAgent.cs and ComposeAgentInstructions.cs live under src/Nueyon.Compose.Application/Agents/Compose. The agent calls Microsoft Agent Framework with no supplied session and requests the ComposeResult JSON schema. It rejects missing text, invalid JSON and blank Content.
- PromptLoader.cs under src/Nueyon.Compose.Application/Prompts supports disk overrides and embedded resources. The production console selected the repository disk prompt tree, as recorded on stderr. The unmodified system, article user and linkedin user prompts are under src/Nueyon.Compose.Application/Prompts/Compose. Each user template receives Format and NarrativeContent.
- Article and LinkedInPost are the exact enum names in src/Nueyon.Compose.Domain/ContentFormat.cs. ComposeInput contains NarrativeForCompose(Content) and CompositionSpec(Format). ComposeResult contains Content. All three types are in src/Nueyon.Compose.Domain. Composer does not receive Research, Synthesis or original sources.
- The shared system prompt frames Compose as a writing and transformation layer and prohibits new meaning, claims, implications and unsupported certainty. Article explicitly permits optional title, introduction, and conclusion, favors narrative development and prohibits unsupported significance or takeaways. LinkedIn emphasizes a focused, quickly readable post, a concrete opening and a natural supported ending.
- src/Nueyon.Compose.Host.Console/CliContracts.cs registers the compose single-agent CLI. Cli.cs resolves prompts and layers configuration. src/Nueyon.Compose.Infrastructure/Agents/OpenAIAgentFactory.cs uses the OpenAI Chat SDK via the Microsoft.Extensions.AI adapter. src/Nueyon.Compose.Host.Console/appsettings.json sets gpt-6-luna. Compose specifies schema only; sampling uses defaults.
- Relevant tests include ComposeAgentResponseParsingTests and NarrativeComposeBoundaryTests in src/Nueyon.Compose.Application.Tests/Agents, InfrastructureServiceExtensionsTests in src/Nueyon.Compose.Infrastructure.Tests, and CLI tests under src/Nueyon.Compose.Host.Console.Tests.
