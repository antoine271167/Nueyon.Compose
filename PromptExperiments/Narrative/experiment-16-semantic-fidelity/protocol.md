# Protocol

Use the existing Narrative-only CLI from the repository root. Every invocation starts a new process. Run the 48 slots in manifest order, alternating first arm by case and repetition. Each arm receives the identical frozen input for each subject. Maintain exact prompt trees and archive CLI result JSON, exit codes, elapsed time and stderr/stdout. The prior smoke call is outside the 48 and excluded from scoring. The provider envelope and transport retries are not exposed by this CLI.

If an environmental dependency fails, stop and report the failure. One repeat of a failed slot is allowed for a transient connection problem or malformed model result, with separate logs and raw result when available. Preserve attempts, retain the first valid result, and never retry a successful invocation. If a slot still fails, record incomplete coverage and do not promote.

Review by opaque ID and subject with arms and order masked. First read the source and exact CLI input, then score the complete brief. Record exact Narrative and source excerpts for each factual issue, its severity, category (entity identity, temporal relationship, actor/object relationship, causality, quantity/scope, other) and origin (upstream, introduced, amplified). Review F1, F2 and borderline editorial cases (weighted score 3.40 through 3.60 or any core axis below 3) again before unmasking. Record changes and reviewer limitations.

Use the Experiment 15 definitions. F0 preserves factual meaning, F1 is minor/repairable without changing central meaning, and F2 materially changes an important claim or relationship. Use maximum severity per output. Score direction, development, Compose usability, resolution and concrete evidence as integers 1 (unusable) through 2 (major rework), 3 (acceptable), 4 (strong) and 5 (distinctive and compelling). Weights are 25, 25, 25, 15 and 10 percent. Editorial pass means weighted score ?3.50 and each core axis ?3. Judge usability as editorial potential after factual repair. A supported plain ending is sufficient. Track format-specific prescriptions separately.

GO requires all of the following: zero B F2 in each set of 12; at least 20/24 B editorial passes; B mean weighted score no more than 0.15 below A; no B core criterion mean more than 0.25 below A and no more than two additional below-3 outputs on any core criterion; at least two fewer regression F2 outputs than concurrent A; no newly recurring B issue category (present in at least two B outputs, absent from A); all 48 valid results with intact frozen hashes, metadata and reviews; zero format-specific B prescriptions. Comparisons are descriptive experimental thresholds, with no significance-test claim. Any failed mandatory gate is NO-GO.

Reviewer is the same assistant in both passes. Knowledge of historical error patterns and sensitivity to prompt wording limit blinding. Regression cases are fixed; holdout breadth is small, with three stochastic repetitions per case. No inference to universal reliability.
