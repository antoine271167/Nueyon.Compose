# Experiment 17 protocol

Use archived Narrative JSON from Experiments 13, 14 and 16, and Experiment 15 for historical labels. Inventory every scored archive entry and deduplicate by SHA-256 of original output bytes. Select the first unique entry per declared subject, historical fidelity stratum and preferred experiment in inventory order. This is a purposive diagnostic sample. Review complete briefs against stored evidence before calls. Freeze subject split, references, byte hashes and reviewed labels before writing the candidate. Wolf and Webb are development subjects. All other subjects are evaluation only. The archived sources vary from longer extracts to compact curated fixtures and include synthetic cases.

Run the same prompt in S and S+Source with the source field as the only input difference. Alternate which condition runs first across cases. Run one attempt per condition per case, archiving all failures and JSON validation. Run development and evaluation without tuning. Use no external tools in the validator. Judge excerpts against the exact input. Independent of model results, use F2 for material change, F1 for a minor ambiguity, and F0 for supported meaning. A FAIL is a positive at output level. REVIEW counts as a non-positive with separate workload. Match findings to the frozen factual issue, including category aliases where the semantic claim is the same. Report both status counts and evidence-backed finding coverage. A strict evidence actionability check requires verbatim excerpts, evidence sufficient for the asserted judgment, and a correction that resolves the discrepancy. Report additional flags and their grounding manually.

Frozen thresholds per condition are recall and precision at least 90%, false-positive rate at most 10%, actionable evidence at least 90% of confirmed findings, and no recurring miss on entity or temporal errors. GO also requires at least five independent positive subjects spanning the two priority categories and evidence of specificity beyond the development cases. CONDITIONAL GO applies if detection and specificity meet the targets but independence or breadth is inadequate. NO-GO applies when neither condition meets quality targets or evidence or review burden makes use unsuitable. Any invalid responses preclude GO and are separately tallied, with no recovery by rerunning a successful response. The binary metrics are computed on valid responses with coverage reported explicitly. No inference about population performance from this stratified cohort.
